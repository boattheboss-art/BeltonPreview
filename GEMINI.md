# Coding and Communication Standards

## Zero Emojis Invariant (Strict Rule)
1. **Never use emojis in code**:
   - No emojis in source code files (`.js`, `.html`, `.css`, `.py`, `.sql`, `.sh`, `.bat`, etc.).
   - No emojis in code comments, documentation strings, function descriptions, or variable names.
   - No emojis in console logs (`console.log`, `print`, `logger`, terminal output).
   - No emojis in UI labels, placeholder text, titles, or button texts (use plain text or SVGs instead of emojis).
2. **Never use emojis in responses**:
   - Responses to the user must maintain a strict zero-emoji policy across all explanations, summaries, and reports.
