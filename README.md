# คู่มือการใช้งาน: Blender Web Live Sync (ระบบสองมือตรวจจับฟิสิกส์ลากดึงแบบประกอบงาน)

โปรแกรมตัวช่วยนี้ได้รับการอัปเกรดให้รองรับ **ระบบตรวจจับฝ่ามือ 2 ข้างพร้อมกัน (Dual-Hand WebAR)** ทำให้พี่สามารถส่งตรงโมเดลจาก Blender มาถือบนมือซ้าย และใช้มือขวาหนีบจับชิ้นส่วนดึงขยับออกมาลอยในอากาศกลางห้องพรีเซนต์ได้สดๆ!

## ✊🖐️ วิธีควบคุมนำเสนอ 2 มือคู่กัน (Holographic Assembly)

ยื่นฝ่ามือทั้ง 2 ข้างเข้ามาหน้ากล้อง และให้เล่นตามบทบาทดังนี้ครับ:

#### 1. มือซ้าย (ฝั่งซ้ายของจอ) $\rightarrow$ "ตัวถือบอร์ด/โมเดลหลัก"
* ใช้สำหรับแสดงพิกัดนำเสนอ โมเดลจะเกาะติดอยู่บนอุ้งมือซ้ายนี้ และพี่ขยับบิดเอียงข้อมือซ้ายนี้เพื่อ **"หมุนเปลี่ยนมุมมองของโมเดล 3D"** ได้รอบทิศทาง

#### 2. มือขวา (ฝั่งขวาของจอ) $\rightarrow$ "ตัวประกอบและดึงชิ้นงาน"
* จะมี **"วงแหวนเลเซอร์สีแดง"** ลอยอยู่ตามชี้ที่ปลายนิ้วมือขวาของพี่:
  * **วิธีการหยิบจับชิ้นส่วน:** เล็งวงแหวนเลเซอร์สีแดงไปแตะใกล้ๆ ชิ้นส่วนโมเดลที่ต้องการ (เช่น พอร์ต, ตัวซีพียู, แรม) จากนั้น **"ทำการกำมือ หรือ ทำนิ้วจีบหนีบ" (Pinch)** $\rightarrow$ *ตัววงแหวนเลเซอร์จะเปลี่ยนเป็นสีเขียวและดูดล็อกชิ้นส่วนนั้นให้ลอยติดตามปลายนิ้วมือขวาของพี่ทันที!*
  * **วิธีการดึงขยับ:** ขยับมือขวาไปมาบนอากาศ ชิ้นชิ้นงานนั้นจะหลุดยืดลอยขยับตามนิ้วมือพี่ไปในอากาศอย่างอิสระ 360 องศา
  * **วิธีการประกอบกลับ (Assemble):** เลื่อนมือขวาพาชิ้นงานกลับไปวางใกล้ตำแหน่งเดิมบนบอร์ด (ระยะน้อยกว่า 0.8 หน่วย) จากนั้น **"แบมือออก"** $\rightarrow$ *ชิ้นส่วนจะดีดดังเป๊าะสวมล็อกกลับเข้าบอร์ดตามเดิม พร้อมมีเสียงฉลุยแสดงสถานะผ่านเกณฑ์การประกอบ!*
  * **วิธีการปล่อยลอยค้าง (Manual Explode):** ดึงชิ้นส่วนออกไปไกลๆ แล้วกางแบมือปล่อย $\rightarrow$ *ชิ้นงานจะลอยค้างอยู่กลางอากาศตรงจุดนั้น ไม่ตกลงมา*

### 🚀 วิธีการทดสอบรันระบบ
1. ใน Blender สั่ง Run Script (สคริปต์ออโต้เซฟตัวเดิม)
2. ดับเบิ้ลคลิกเปิดไฟล์ **`ClickToRun.bat`** ในโฟลเดอร์โครงการ
3. สังเกตและหัดโบกมือ 2 ข้างทดลองถอดประกอบชิ้นงานบนอากาศ และกดปุ่ม `Ctrl + S` ใน Blender เพื่ออัปเดตรูปร่างใหม่ๆ ได้สดๆ ตลอดเวลาครับ!
